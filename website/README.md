# Aquadro POS — Official Website & Download Portal

Site officiel et portail de téléchargement direct pour **Aquadro POS** (Logiciel de Caisse & Gestion de Stock pour l'Algérie).

## Fonctionnalités du Site
- ⚡ **Téléchargement Direct :** Téléchargement instantané de l'installeur Windows (`.exe`) sans redirection vers des pages externes.
- 🔄 **Détection Automatique des Versions :** Synchronisation dynamique avec les dernières releases signées (`sigoulojia/aquadro-releases`).
- 🎨 **Design Moderne & Bilingue :** Support complet du Français et de l'Arabe (RTL), adapté au marché algérien (TVA, DZD, code-barres).
- 🚀 **Prêt pour le déploiement Vercel :** Configuration `vercel.json` incluse avec en-têtes de sécurité et cache optimisé.

## Déploiement sur Vercel
1. Connectez votre compte GitHub sur [Vercel](https://vercel.com).
2. Importez le dépôt `sigoulojia/aquadro-website`.
3. Cliquez sur **Deploy** (aucune configuration complexe requise, détection automatique du site statique).
